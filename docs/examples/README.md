# Documented engine examples

The following sub-directories mirror the .zip project downloads for the
[RiskScape Engine documentation](https://engine-docs.sites.riskscape.nz).
For example, the getting-started/ directory corresponds to the getting-started.zip
download in the engine documentation.

The GIS data files (i.e. .shp, .tif files) have been excluded here - for the
full working projects including input data, use the .zip files in the Engine documentation.
However, there are metadata files that describe the shape of the input data,
such as the attribute names, CRS information, and geospatial bounds.
So instead of a `Buildings_SE_Upolu.shp` file, there is a `Buildings_SE_Upolu.shp.txt`
that describes `Buildings_SE_Upolu.shp`'s metadata.
