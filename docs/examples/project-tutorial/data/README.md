# Acknowledgements

The data used in this tutorial was provided by the sources listed below.
All the data files have been modified slightly for the purposes of the tutorial.

- Samoa_constituencies.shp and ws_districts.shp were sourced from the [PCRAFI](http://pcrafi.spc.int)
 (Pacific Risk Information System) website. Some attributes were removed or renamed
 from the original data files. The 'Marine Area' polygon was added.

- Buildings_SE_Upolu.shp and Buildings_SE_Upolu_centroids.csv were provided by Earth Sciences New Zealand and
  were originally based off [OpenStreetmap](https://www.openstreetmap.org) data.
  They have been modified significantly: attributes removed, spatially filtered (i.e. rows removed),
  the 'ID' attribute data was replaced, and the centroid of the geometry was used for the CSV file.

- MaxEnv_All_Scenarios_50m.tif was provided by Earth Sciences New Zealand. It has been modified slightly to
  reduce the file size.

- problematic.shp was based on the above files and has been modified
  to introduce minor problems.
