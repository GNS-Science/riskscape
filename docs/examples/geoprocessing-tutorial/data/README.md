# Acknowledgements

The data used in this tutorial was provided by the sources listed below.
All the data files have been modified slightly for the purposes of the tutorial.

- Samoa_constituencies.shp was sourced from the [PCRAFI](http://pcrafi.spc.int)
 (Pacific Risk Information System) website. Some attributes were removed or renamed
 from the original file.

- MaxEnv_All_Scenarios_50m.tif was provided by Earth Sciences New Zealand. It has been modified slightly to
  reduce the file size.

- Roads_SE_Upolu.shp was originally sourced from https://download.geofabrik.de/australia-oceania/samoa.html
  and is based on [OpenStreetmap](https://www.openstreetmap.org) data.
  The original OpenStreetMap data file is licensed under the Open Database 1.0 License. See
  www.openstreetmap.org for details about the project.
  The data has been modified significantly: attributes removed, spatially filtered (i.e. rows removed),
  and the `length` and `num_lanes` attributes were added. Note that `num_lanes` was arbitrarily assigned
  based on the `fclass`  attribute.
