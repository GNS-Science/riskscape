# Acknowledgements

The data used in this tutorial was provided by the sources listed below.
All the data files have been modified slightly for the purposes of the tutorial.

- Buildings_SE_Upolu.shp was provided by Earth Sciences New Zealand and was originally based off
  [OpenStreetmap](https://www.openstreetmap.org) data.
  They have been modified significantly: attributes removed, spatially filtered (i.e. rows removed),
  and the 'ID' attribute data was replaced.

- The tsunami inundation GeoTIFF files (`*.tif`) were provided by Earth Sciences New Zealand. They has been modified slightly to
  reduce the file size.
