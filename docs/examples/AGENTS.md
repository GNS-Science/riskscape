# RiskScape Examples — Agent Instructions

This file provides guidance for AI assistants using the `docs/examples` directory.
This directory contains the project files from the example `.zip` downloads in the
RiskScape Engine documentation.

Companion files:
- README: https://raw.githubusercontent.com/GNS-Science/riskscape/refs/heads/main/docs/examples/README.md
- Engine docs: https://engine-docs.sites.riskscape.nz
- Engine docs for LLMs: https://engine-docs.sites.riskscape.nz/llms.txt

*Important*: These examples help you to understand the RiskScape Engine documentation.
For helping a user to build new RiskScape models, the best resource is:
- Subpipeline library agent instructions: https://raw.githubusercontent.com/GNS-Science/riskscape/refs/heads/main/subpipelines/AGENTS.md

## Input data metadata files

The GIS input data files (`.shp`, `.tif`, etc.) have been excluded from this directory
since they are binary files. Instead, each GIS file has a corresponding `.txt` metadata
file describing its contents.

For example, instead of `Buildings_SE_Upolu.shp` there is `Buildings_SE_Upolu.shp.txt`
describing `Buildings_SE_Upolu.shp`.

The metadata files are plain text and contain information such as:
- Attribute names and types (vector data)
- CRS (coordinate reference system)
- Geospatial bounds
- Feature count (vector data)

The `.txt` metadata help to demonstrate how attributes referenced in a bookmark or
pipeline correspond to the input data. These `.txt` files were generated by the
`riskscape bookmark info FILENAME` command.


## Relationship to the subpipeline library

The subpipeline library in `subpipelines/AGENTS.md` is the latest approach
to building models using reusable components. Whereas the examples in the
engine docs are generally older and so can sometimes use older pipeline features.

However, the engine docs project files can contain more examples of configuring
bookmarks and functions, which the subpipeline library has less of.

For the full working projects including input data, use the `.zip` files linked from
the Engine documentation pages above.
