# README

This directory contains worked examples of infrastructure risk models for a volcanic eruption.
The hazard data used in this example is the ‘Scenario C’ Māngere Bridge eruption,
produced as part of the Determining Volcanic Risk in Auckland (DEVORA) research programme.
https://www.devora.org.nz/

For a detailed explanation of the models, refer to:
https://engine-docs.sites.riskscape.nz/case-studies/devora.html

## Quickstart

To run these models requires:
- RiskScape is setup to use CPython
https://engine-docs.sites.riskscape.nz/reference/python/cpython.html#configuring-cpython-support-in-riskscape
- A Koordinates secret is configured in order to use the LINZ layers
https://engine-docs.sites.riskscape.nz/reference/config/secrets.html#koordinates
