# Acknowledgements

The data used in this project was provided by the sources listed below.
All the data files have been modified slightly for the purposes of RiskScape tutorials.

- Samoa_constituencies.shp was sourced from the [PCRAFI](http://pcrafi.spc.int)
  (Pacific Risk Information System) website. Some attributes were removed or renamed
  from the original file.

- MaxEnv_All_Scenarios_50m.tif and MaxEnv_All_Scenarios_10m.tif were provided by
  [Earth Sciences New Zealand](https://www.earthsciences.nz/). They have been modified slightly
  to reduce the file size.

- Roads_SE_Upolu.shp was originally sourced from https://download.geofabrik.de/australia-oceania/samoa.html
  and is based on [OpenStreetmap](https://www.openstreetmap.org) data.
  The original OpenStreetMap data file is licensed under the Open Database 1.0 License, refer to
  https://opendatacommons.org/licenses/odbl/1-0/
  The data has been modified significantly: attributes have been removed, renamed, and added.
  The data has been spatially filtered (i.e. rows removed).

- Buildings_SE_Upolu.shp was provided by Earth Sciences New Zealand and was originally based off
  [OpenStreetmap](https://www.openstreetmap.org) data, and so would be licensed under the
  Open Database 1.0 License (https://opendatacommons.org/licenses/odbl/1-0/).
  It has been modified significantly: attributes removed, spatially filtered (i.e. rows removed).

- wsm_t_pop_2025.tif is the 'Population Grid Samoa 2025' data sourced from https://pacificdata.org/
  This data is licensed under a Creative Commons Attribution 4.0 License.

- The .csv files in functions/ were derived from Python code originally provided by Earth Sciences New Zealand.
